# Tooltip must be define on table's fields and not on page's fields

## Description

Tooltip can be define on field for table and tableextension.
Do not add tooltip on field's page.

## Anti Pattern

Do not omit Tooltip in page, pageextension if object is not linked with a field of a table or a tableextension
